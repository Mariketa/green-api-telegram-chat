# Telegram Chat — GREEN-API

Простое веб-приложение на React для отправки и получения текстовых сообщений Telegram через GREEN-API.

## Требования

Для локального запуска необходимы:

- Node.js 18+
- npm

Проверить установку:

```bash
node -v
npm -v

Локальный запуск
1. Скачать или клонировать проект.
2. Перейти в папку проекта:
   cd green-api-telegram-chat
3. Установить зависимости
   npm install
4. Запустить проект
   npm run dev
5. Открыть адрес, который появится в терминале
   По умолчанию
   http://localhost:5173

Использование
После запуска приложения:
1. Ввести IdInstance
2. Ввести apiTokenInstance
3. Нажать "Войти"
4. Создать новый чат
5. Ввести номер телефона получателя
6. Отправить текстовое сообщение
Ответные текстовые сообщения из Telegram автоматически отображаются в чате

GREEN-API

Для работы приложения необходим активный Telegram-инстанс GREEN-API
https://green-api.com/telegram/?utm_source=chatgpt.com
